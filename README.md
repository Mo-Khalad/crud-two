<h1>CRUD TWO</h1>

<P>This project features an attractive, elegant, and responsive design that adapts to all screen sizes
  . It includes full CRUD functionality—allowing users to add, edit, search for
  , and delete products—as well as data validation and the persistence of data in `localStorage` upon page refresh.</P>

  <h3>Tools</h3>
  <p> Html , Css , Bootstrap and Js </p>
  
  <h3>Features</h3>
  <ul>
    <li>An elegant and attractive design that adapts to all screen sizes.</li>
    <li>It features the ability to add, edit, and delete products.</li>
    <li>It includes additions for multiple elements that share the same data.</li>
    <li>Search by title and categories</li>
    <li>Validate the data and save it to `localStorage` to ensure it persists when the page is refreshed.</li>
  </ul>
